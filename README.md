# BFMScan: Enabling Explicit Angle-Resolved Sensing via Beamforming Feedback Matrix

This repository will host the code and dataset for the paper:

> Bofan Li, Zhuoyuan Liu, Zhankai Ye, Weikuan Yu, and Xin Liu. **BFMScan: Enabling Explicit Angle-Resolved Sensing via Beamforming Feedback Matrix.** *Proceedings of the ACM on Interactive, Mobile, Wearable and Ubiquitous Technologies (IMWUT)*, Vol. 10, Issue 3, Article 122, 2026. DOI: [`10.1145/3832009`](https://doi.org/10.1145/3832009).

The paper is open access in the [ACM Digital Library](https://doi.org/10.1145/3832009).

## Status

The code and dataset release is being prepared and will be added here.
